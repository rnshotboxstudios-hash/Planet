PLANET — MISSION WORKSPACE PREVIEW

Extract the ZIP and open planet-demo.html in a modern WebGL-capable browser.
If your browser blocks local HTML, serve this folder using a local web server.

The Scout's first task option is Scour the Galaxy. Select LOAD TASK to save that
research mission and read the complete instructions. This does not run a search.
BLAST OFF is the separate mission launch action.

The single HTML file includes the room graphics, code, styles and fonts.
Real AI tasks require Planet's running server and configured service connections;
the ZIP is a visual/workspace preview, not a self-contained paid AI service.
No website template is the default action. Task outputs belong in the real outbox.
Sales, posting and payments are not connected in this development version.

Creative directions and room state are saved on this browser.
